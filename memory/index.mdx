The canonical institutional memory of the company. Every folder answers one question:

- **Brand** — who are we?
- **Product** — what are we building?
- **Customers** — who do we serve?
- **Market** — what is happening around us?
- **Tech** — how does it work?
- **Content** — what do we communicate?
- **Growth** — how do we grow?
- **Operations** — how do we run?
- **Agents** — how do our agents work?

> Convention: each folder\'s `index.mdx` is housekeeping (what/why the folder exists). Actual content lives in sibling files (e.g. `customers/feedback.md`).

> Rule for all `memory/*` docs: document what the **code doesn't explain** — intent, principles, contracts, and decisions. Never duplicate what the code already is the source of truth for (routes, schema, file paths, query details). If it will drift with code, it belongs in code. If it explains *why* code must be a certain way, it belongs here.
