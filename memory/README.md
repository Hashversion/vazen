the canonical institutional memory of the company.

this directory answers the questions that help humans and agents understand, build, operate, and grow the company.

* `tech/` → how does it work?
* `product/` → what are we building?
* `brand/` → who are we?
* `customers/` → who do we serve? (`feedback.md` for generalizable signals; `README.md` is housekeeping only)
* `market/` → what's happening around us?
* `content/` → what do we communicate?
* `growth/` → how do we grow?
* `operations/` → how do we run?
* `agents/` → how do our agents work?

> convention: `README.md` in each folder is housekeeping (what/why the folder exists). actual content goes in separate files (e.g. `customers/feedback.md`).
> links must be extension-less — write `[Discovery](../product/discovery)` not `[Discovery](../product/discovery.mdx)` (Blume routing).
