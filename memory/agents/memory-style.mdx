---
title: Memory Style
---

## Goal

- Decide faster, not read longer.
- If it doesn't change a decision, delete it.

## Rules

- Bullets + tables only. No paragraphs, no essays.
- One idea per bullet. Max 1 line.
- Tables for comparisons: `| Thing | Def | Action |`.
- Lead with answer, then why (1 fragment max).
- Terse over complete. Short memory > full coverage.
- No intro/outro sentences. No "in conclusion".
- Skip vanity context. Keep only: def + signal + action.

## Format

- `##` sections, max 5 per file.
- Prefer: North star → What to watch → Action if low → Skip → Cadence.
- Numbers over adjectives. `30% sessions → click` not `high engagement`.
- Contracts (events, rules) as code/plain lists, no prose.

## Anti-patterns

- Paragraphs > 2 lines.
- Background essays, generic advice.
- Duplicating what code is truth for.
- Hedging: "might, could, various". State it or drop it.
