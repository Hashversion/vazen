Docs, demos, and templates, posted where builders already look. Handles live in [brand/socials](../../brand/socials).

| channel | use |
|---|---|
| github | repo, releases, discussions, templates |
| docs | `vazen.dev/docs`: setup, toolkit, stack |
| demo | `web.vazen.dev`: reference app that proves the docs |
| x | ship notes and releases (`@stackfound`) |
| reddit | answer first, link only when it helps |
| youtube | setup walkthroughs and stack explainers |

Skip engagement bait. List in starter galleries and roundups only if they send qualified clones; prune the rest. Search details live in [growth/seo](./seo). Agent surfaces live in [Machine Discoverability](../../tech/discoverability); every machine surface renders from the same published docs as HTML.
