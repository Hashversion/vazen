---
title: SEO & AEO
description: How vazen docs earn search and answers
---

One query, one clear answer, with a runnable path. Skip keywords we can't answer better than what's ranking.

Target starter and setup queries our docs answer best. Domain is `vazen.dev`, docs at `/docs`, no date slugs. Every guide links to the demo route and repo path that prove it.

Write to get cited: lead with a 40–60 word answer, keep each H2 self-contained, state versions and commands instead of adjectives. If a page reads useless as plain markdown, answer engines can't use it either.

Every page ships its own title, description, canonical, OG image, and JSON-LD that matches the visible page. Sitemap lists published pages only, with honest `lastmod`. Robots allows all crawlers by default. Feeds carry releases and changelog entries, each linking back to its canonical page.
